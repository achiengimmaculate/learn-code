# Lesson 01 - HTML is a skeleton, not a painting

## Before you touch the keyboard

On freeCodeCamp, work through the start of **Responsive Web Design**, the "Learn HTML by Building a Cat Photo App" section. Do the first 20 or so steps. Stop when you hit anything about CSS.

That is your theory. Come back here for the reality.

## The one idea

HTML does not decide how things look. HTML decides what things **are**.

A heading is a heading because it is important, not because it is big. A list is a list because the items belong together, not because you want bullets. Looks come later, from CSS. Beginners get this backwards and it costs them for years.

## Your task

Create a file called `index.html` in this folder. Build a page about yourself. Not a pretty one. A correct one.

It must contain:

- The document skeleton: doctype, html, head, body
- A page title that shows in the browser tab
- One main heading with your name
- At least two sections, each with its own subheading
- A paragraph of real text under each subheading
- A list of at least three things (your choice: skills, goals, favourite foods)
- One link to a website you actually use
- One image (any image URL from the web is fine) with proper alt text

Do not add any colours, fonts, or styling. Resist it. This lesson is about structure only.

## Seeing your work

Open Terminal and run:

```
open ~/learn-code/01-html-css/lesson-01/index.html
```

It will open in your browser. It will look plain and ugly. That is correct and expected.

## When you are done

Tell Claude "lesson 1 done". It will read your actual file and review it.

## Questions you should be able to answer afterwards

1. What is the difference between `<head>` and `<body>`?
2. Why does an image need alt text?
3. Why is it wrong to use a heading tag just because you want big text?
