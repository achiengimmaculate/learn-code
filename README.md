# learn-code

My full stack learning workshop. Theory comes from freeCodeCamp. Practice happens here.

## The rules

1. **I type the code. Claude does not.** If Claude writes the answer for me, I have learned nothing.
2. **Claude reviews, explains, and sets the next exercise.** It can show me tiny examples of a concept, but the exercise itself is mine.
3. **I am allowed to be stuck.** Stuck is where learning happens. I say what I tried and what I expected.
4. **Every lesson ends with me explaining it back in my own words.** If I cannot explain it, I do not know it yet.

## How a lesson works

- `BRIEF.md` tells me what to build and what to learn first on freeCodeCamp.
- I write my code in the lesson folder.
- I tell Claude "done" and it reviews my actual code, line by line.
- Claude asks me questions about my own code. Then we move on.
