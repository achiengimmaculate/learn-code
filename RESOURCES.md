# Where to find the theory

## First, the important warning

The freeCodeCamp Certified Full-Stack Developer path is roughly **1,800 hours**: six certifications at about 300 hours each, plus a capstone. Our plan is about **600 hours**.

**We are not chasing certificates.** freeCodeCamp is our textbook and we read only the chapters that match the week we are on. Chasing all seven certifications inside 27 weeks is the fastest way to fall behind and quit. Finish the certs later, at your own pace, if you want them.

## How the seven freeCodeCamp items map to our 27 weeks

| freeCodeCamp certification | Our weeks | Do we do all of it? |
|---|---|---|
| Responsive Web Design | 1 - 3 | Most of it. Skip the extra practice projects. |
| JavaScript Algorithms and Data Structures | 4 - 8 | The JavaScript half, yes. The algorithms half, skim. |
| Front End Libraries | 9 - 13 | The React sections only. Skip jQuery, Sass, Bootstrap. |
| Python Programming | 15 - 18 | Yes, this one maps well. |
| Relational Databases | 19 | The SQL sections. Skip the long Bash and Git workshops, we cover those in week 1. |
| Back End Development and APIs | 24 | **Node and Express, not Flask.** Useful for our port week, not for weeks 20 to 23. |
| Certified Full-Stack Developer Curriculum | not used directly | This is the 1,800 hour umbrella. Ignore it as a target. |

**The Flask gap is real.** freeCodeCamp's backend certification teaches Node and Express. It does not teach Flask at all. Weeks 20 to 23 need a different source, listed below.

## The best free source for each topic

### HTML and CSS (weeks 1 to 3)
- **MDN Web Docs** at developer.mozilla.org. This is the actual reference the whole industry uses. Learn to read it early, it pays off forever.
- **CSS-Tricks Guide to Flexbox** and **Guide to Grid**. The two best pages on the internet for layout.
- **Flexbox Froggy** and **Grid Garden**. Browser games that teach layout. Genuinely effective, takes an hour each.

### JavaScript (weeks 4 to 8)
- **javascript.info**. The Modern JavaScript Tutorial. Deeper and better written than most paid courses.
- **MDN JavaScript reference** for looking things up.

### React (weeks 9 to 13)
- **react.dev**, the official React docs. These were rewritten and are now excellent. Do the "Learn React" tutorial.

### Python (weeks 15 to 18)
- **Automate the Boring Stuff with Python**, free to read at automatetheboringstuff.com.
- **The official Python tutorial** at docs.python.org/3/tutorial.

### SQL (week 19)
- **SQLBolt** at sqlbolt.com. Interactive, short, excellent.
- **PostgreSQL Tutorial** at postgresqltutorial.com.

### Flask (weeks 20 to 23) - the gap
- **The Flask Mega-Tutorial** by Miguel Grinberg. Free online, long, and the standard recommendation for good reason.
- **Official Flask documentation** at flask.palletsprojects.com. Start with the Quickstart and the Tutorial.
- freeCodeCamp's **YouTube channel** has multi-hour Flask courses, separate from the certifications.

### Next.js (week 24 onward)
- **The docs inside this machine**, at `~/lucim-polls/node_modules/next/dist/docs/`. This version of Next.js differs from what is online and from what most tutorials assume. Read the local docs, not blog posts.

## How notes work here

Two kinds of notes, and they do different jobs.

### Notes I write for you: `CONCEPTS.md`
Every week gets one. It explains the ideas in plain language, including the parts tutorials skip because they assume you already know them. Read it before the freeCodeCamp work, then again after.

### Notes you write for yourself: `NOTES.md`
Every week gets one of these too, and it is **blank until you fill it**.

This is not busywork. Writing something in your own words is the test of whether you understood it. If you cannot write it down, you did not learn it, you only watched it. Copying my `CONCEPTS.md` into your `NOTES.md` defeats the entire point.

The template is in `NOTES-TEMPLATE.md`. Copy it into each week's folder.
